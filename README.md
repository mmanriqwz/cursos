# Sistema de Gestión de Cursos

## Descripción
Este proyecto consiste en un Sistema de Gestión de Cursos desarrollado en Java. Su objetivo es representar y gestionar la información de estudiantes, profesores, cursos, horarios, inscripciones y calificaciones.

## Tecnologías utilizadas
- Java
- Spring Boot
- Maven
- Visual Studio Code

## Clases del sistema
- Persona: representa los datos generales de una persona.
- Estudiante: representa a los estudiantes.
- Profesor: representa a los profesores.
- Curso: representa los cursos disponibles.
- Horario: contiene la información de los horarios.
- Inscripcion: representa las inscripciones a los cursos.
- Calificacion: representa las calificaciones de los estudiantes.
